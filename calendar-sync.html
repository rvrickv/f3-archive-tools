F3 Calendar Sync

A small personal project maintained by Rick Villela.

F3 Calendar Sync is a private utility that keeps the F3 Salt Lake region's workout and event schedule up to date in Google Calendar. It creates, updates and removes calendar events so the region's leaders and members can see the current schedule.

The app is not offered to the public. It is used only with the calendar account it was built for, and sign-in uses Google's standard OAuth consent screen.
